# Third-party notices

## Penstock `io` module

`Freshet-Data/src/io.fsht` is adapted verbatim from the `modules/io.fsht`
standard-library module in the [Penstock project](https://github.com/PolskaKrowa/Penstock).
It is included so the Freshet-Data project can resolve `import io;` when a
Penstock installation has not installed its standard-library module files.
